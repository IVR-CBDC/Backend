# ADR

Короткие записи о решениях, которые иначе придётся восстанавливать по
коммитам и комментариям в values.

Нумерация начинается с 0006 не по ошибке: решения 1–5 приняты раньше и
описаны в планах (`docs/superpowers/plans/`), отдельными ADR они не
оформлялись. Заводить их задним числом значило бы переписывать историю по
памяти — а ADR ценен именно тем, что фиксирует контекст в момент решения.
Номера 0006+ — решения плана 08.

| [0007](0007-secrets-only-in-k3s.md)              | Secret только в k3s, в compose пароли открыты             |
| [0008](0008-frontend-listens-on-8080.md)         | SPA слушает 8080, а не 80                                 |
